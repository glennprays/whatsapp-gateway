[ 01 / FLOW ]

Your backend stays stateless. waga holds the line.

Sessions, device keys, reconnects and pacing live in the gateway. Your services make HTTP calls out and receive signed webhooks back, in any language.

01 · Send

One HTTP call per action

JWT-authenticated REST for text, media, polls, reactions, edits and group ops. Add Idempotency-Key and a retried request replays instead of sending twice.

02 · Hold

Sessions that stay up

waga owns device keys, reconnects and the outbound pacer, so bursts from your side get paced instead of hitting WhatsApp all at once.

03 · Receive

Signed events back

Incoming messages and session changes fan out to every subscribed URL, signed with X-Webhook-Signature.

[ 02 / CAPABILITIES ]

Everything between your backend and WhatsApp.

The parts you would otherwise build yourself: event fan-out, session tracking, pacing, media handling and delivery retries.

● Webhooks

11 events, filtered per subscription

Register several URLs per account, each with its own event filter and HMAC secret. Secrets are never returned by the API.

message.incoming message.queued message.sent message.failed session.connected session.disconnected session.logged_out session.banned session.connect_failure session.replaced session.reachout_timelocked
● Multi-device

Many accounts, one instance

QR or pairing-code login per number, with automatic reconnects and honest session states.

62812345xxxxconnected
62877812xxxxconnected
14155550xxxxnever_paired

● Outbound pacer

Bursts get smoothed

Every send and mutation passes a ban gate, a per-recipient cap and a per-account token bucket.

rate 1/sburst 5recipient 10/60s
● Media

8 message types

Send them all, plus replies, mentions, reactions, edits and deletes. Incoming media is stored and linked in the webhook.

textimageaudiovideo documentlocationpollsticker
● Delivery

Queue it, or don't

Run RabbitMQ for retries and a dead-letter queue, or go direct and keep failed deliveries encrypted for 7 days.

rabbitmqretries · DLQ
directencrypted · 7d
● Self-hosted

One binary. Your servers, your data.

Docker or bare metal, SQLite to start and PostgreSQL in production. MIT licensed, no per-message pricing.

$ go build -o waga ./cmd/api $ ./waga # restores every paired session from SQLite or PostgreSQL # then serves REST on :3000

[ 04 / AGENTS ]

Give your agents WhatsApp. Not the keys to it.

waga ships an MCP server. Claude, Cursor, Claude Code and OpenCode can send messages, read contacts and groups, and manage webhooks through the same gateway your backend uses.

Claude DesktopClaude CodeCursorOpenCode
Scoped by design. Group mutations, community ops, the admin plane and metrics are not exposed, so an agent can't make account-wide changes.
